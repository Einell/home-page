# 0.2 开发候选

本分支尚未发布；公开安装版本仍为 0.1.0。

- 搜索框输入内容后按 `⇧↵`，或点击「记一笔」，会追加到 Inbox 笔记；设置中可改为今日日记。成功后清空输入框，失败时保留原文。之前 `⇧↵` 的「在新标签打开搜索结果」行为已改为快速记录。
- 「今天」卡片显示今日日记是否存在、正文字符数，点击可打开或创建日记。日记路径与模板取自内置「日记」插件设置。未启用时不显示。
- 「常用」读取内置「书签」插件的文件和搜索书签，包含书签组内的项目；没有书签时不显示。

快速记录默认写入库根目录的 `Inbox.md`，可在设置中改为其他库内 Markdown 路径。选择日记时必须启用内置「日记」插件。卡片只提供摘要和入口；任务与日程适配器留待后续版本。
